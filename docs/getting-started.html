Getting Started

Download Student KitStudent Guide

  1. Unzip and start

    Extract the ZIP to a short folder path. On Windows, open START_HERE_WINDOWS.cmd. Do not run it inside the ZIP.

    Windows tested. For macOS or Linux, see the Student Guide. First-time setup may need internet access.

  2. Add your agent

    Copy workspace/TEMPLATE_agent.py to workspace/YOUR_NETID.py using your NYU NetID. Edit your strategy, then use Add Your Agent and Choose the Agent to Test.

  3. Validate and play

    Choose Validate Your Agent. Fix any failed checks. Then use Run Test Games against Random or Greedy and open View Game Report.

    READY TO SUBMIT means local checks passed, not an official grade or originality check.

  4. Submit your file

    Upload exactly one self-contained YOUR_NETID.py file to the designated Gradescope assignment by November 23, 2026, 5:00 PM ET. Do not submit the Student Kit, a virtual environment, or your local reports.

    This website does not accept uploads or run agents.

Public agent name

ChessAgent.name may appear on the leaderboard. Choose a non-identifying name: no NetID, real name, email, or personal information. Your filename still uses your NetID.
