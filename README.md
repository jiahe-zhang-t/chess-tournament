# Chess Tournament

ECE-GY 6263 Game Theory · Fall 2026

Build and test your chess agent locally. Compete in the class tournament.

[Website](https://jiahe-zhang-t.github.io/chess-tournament/)

## Getting Started

1. Download and extract the [Starter](https://jiahe-zhang-t.github.io/chess-tournament/downloads/Chess_Agent_Competition_Starter_v1.0.zip).
2. Follow the [Student Guide](https://jiahe-zhang-t.github.io/chess-tournament/materials/guide.pdf) to open Chess Agent Test Space.
3. Add your agent, validate it, and play practice games.

Try the [Example Agent](https://jiahe-zhang-t.github.io/chess-tournament/downloads/abc123.py). You do not need to clone this repository.

## Submission

Submit one Python file named with your NetID, such as `abc123.py`, to the designated Gradescope assignment. Do not submit the Starter ZIP.

Practice results are not official scores. Course staff run the official evaluation; this website does not accept uploads or run agents.
